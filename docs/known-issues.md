# เรื่องที่ต้องแก้ในอนาคต

## ความสอดคล้องของเอกสารระหว่างระบบเรากับ FlowAccount

ข้อมูลไหลทางเดียว: ระบบเรา → FlowAccount (FlowAccount ไม่มี webhook แจ้งกลับ)
ถ้ามีการเปลี่ยนแปลงฝั่ง FlowAccount ระบบเราจะไม่รู้

| # | กรณี | ผล | วิธีแก้ / ป้องกัน | ความสำคัญ |
|---|---|---|---|---|
| 1 | ออกใบกำกับภาษีใน FlowAccount สำเร็จ แต่ออกใบเสร็จไม่สำเร็จ (`app/api/admin/receipts/route.ts`) | ระบบเรา rollback ทิ้ง แต่ใบกำกับภาษีค้างใน FlowAccount ถ้ากดออกใหม่จะได้ **ใบกำกับภาษีซ้ำ** | บันทึก `tax_invoice` ทันทีหลังสร้างใน FlowAccount (แยก transaction) ตอนกดซ้ำให้ข้ามไปออกแค่ใบเสร็จ | **สูง (บั๊กจริง)** |
| 2 | มีคนสร้าง / แก้ / ลบ / ยกเลิกเอกสารในเว็บ FlowAccount เอง | ยอดในแดชบอร์ด FlowAccount ไม่ตรงกับระบบเรา | กฎการใช้งาน: ออกเอกสารผ่านระบบเราเท่านั้น FlowAccount ใช้ดูอย่างเดียว (ใส่ในคู่มือ + UAT) | กลาง |
| 3 | FlowAccount สร้างเอกสารสำเร็จ แต่ระบบเราบันทึก DB ไม่สำเร็จ (เน็ตหลุด / DB ล่ม) | มีเอกสารใน FlowAccount ที่ระบบเราไม่รู้ | เกิดยาก แก้ทีละรายการผ่านหน้าตรวจความตรงกัน (ข้อ 6) | ต่ำ |
| 4 | ข้อมูลทดสอบสมัยใช้ FlowAccount จำลอง (ลบตัวจำลองออกแล้ว) เช่น ใบแจ้งหนี้ invoice_id 9–11 (record_id 100xxx) | `flowaccount_record_id` ปลอม ไม่มีใน FlowAccount ออกใบเสร็จต่อไม่ได้ | ล้างข้อมูลทดสอบก่อนใช้งานจริง | กลาง (ก่อน go-live) |
| 5 | ใช้ sandbox ปนกับบัญชีจริง | เอกสารอยู่คนละบัญชี | แยก env: `.env.local` = sandbox, Vercel = บัญชีจริง | กลาง (ก่อน go-live) |
| 6 | ไม่มีเครื่องมือตรวจความตรงกัน | หาเอกสารที่ไม่ตรงกันไม่เจอ | หน้าแอดมิน "ตรวจความตรงกัน": ดึง `GET /{docType}?currentPage=…` จาก FlowAccount มาเทียบกับ `flowaccount_record_id` ใน DB แสดงใบที่มีฝั่งเดียว (ใช้เป็นเคส system test ได้) | ต่ำ (ถ้ามีเวลา) |

### ที่ตรงกันอยู่แล้ว (ไม่ต้องแก้)
- ยอดเงินและ VAT ตรงกันทุกใบที่ทดสอบ
- QR ที่หมดอายุ / ยกเลิก ไม่มีเอกสารทั้งสองฝั่ง (เอกสารออกหลังชำระแล้วเท่านั้น)
- แก้ใบเสนอราคาไม่สำเร็จใน FlowAccount → ระบบเรา rollback ตาม
- ใบแจ้งหนี้ยอดคงเหลือ: ระบบเราผูกกับใบเสนอราคาด้วย `quotation_id` ส่วน FlowAccount อ้างอิงแค่ในหมายเหตุ (ข้อจำกัดของ FlowAccount ที่ upgrade เอกสารได้ครั้งเดียว)

## เรื่องอื่นที่ค้างอยู่
- หน้าแชร์เอกสาร / export PDF ของ FlowAccount sandbox ล่ม (503 / 502) รอ FlowAccount แก้
- แจ้งเตือนทาง LINE OA (`lib/line.ts`) ยังไม่ทำ มี TODO ในโค้ดตามจุดที่เล่มกำหนด
- ระบบ login แอดมิน (Use Case 11) ยังไม่มี
- ฝั่งลูกค้ายังส่งไฟล์สัญญาที่เซ็นแล้วไม่ได้ / ฝั่งแอดมินยังตรวจสัญญาไม่ได้
